<p>Nightfarer Tool is an offline practice tool for Elden Ring Nightreign mainly catered towards Challenge Runners, Hitless Runners & Speedrunners, It also provides a bunch of quality of life options for modders.</p>

**This tool is strictly for offline use only, it directly manipulates game memory which violates the Terms of Service and will most likely lead to a ban if you use this online.**

*Whenever someone tries to enable a cheat toggle in online custom servers the tool will not activate them and instead will send a very heartwarming message :)*

## Features
This tool offers plenty of features such as:
* Auto-Attaching to the game.
* Saving / Restoring position seamlessly.
* Character cheats such as: No Death, No Damage, Infinite Items, Stat Editing, and many more.
* Warping to Day 3 instantly
* Swapping hero and outfits with ease (discards the items, retains level and runes)
* Disable AI / Enemies no Death and more NPC Flags
* Custom Grace Unlocking Presets (with the ability to unlock on game start)
* Lock Gladius' phases / force phases (Both Nightlords)
* Lock Divine Lion's phases / force phases
* Many options for the locked on target.
* Adjusting Game Speed.
* Adjusting FPS Cap.
* No Clip (works with keyboard and mouse)
* Free Cam (works with keyboard)
* Rendering Settings such as: Hitbox View, Event view, Sound view, Ragdolls, High/Low Hit, and more.
* Opening various menus and shops from anywhere.
* Applying / Remove Special Effects as well as seeing active Special Effects on player
* Item Spawn / Item Drop (With the ability to items on an expedition start)
* Changing Weather
* Event Flags checking, activating, and deactivating.
* Unlocking All Nightfarers, Outfits, Expeditions, and Gestures.
* Events Logger.
* Param Patcher.
* Character List (Npc Manager) with features such as warping to the selected entity, AI Viewer and AI Script injections.
* Debug features such as animation IDs (both player and enemies) and Enemy Acts.
* Logo Skip.
* In-Game Overlays for AI Viewer and Boss stats with opacity changing features.
